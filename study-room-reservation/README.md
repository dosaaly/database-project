# study room reservation

this project is a postgresql database for managing study room reservations.

it can be used by a school or university to:

- keep a record of available study rooms
- let students reserve rooms for specific dates and hours
- track confirmed and cancelled reservations
- find rooms by capacity or projector availability
- review room usage and total booked hours
- report reservation activity by student, room, or major
- control database access for read-only and admin users

it stores:

- student details and majors
- room numbers, capacities, and projector availability
- reservation dates, booked hours, and status

the project also includes sql examples for:

- database tables, keys, and constraints
- sample students, rooms, and reservations
- basic queries, joins, grouping, and subqueries
- inserts, updates, deletes, and transactions
- indexes for reservation searches
- read-only and admin database users
